# Gojiberry AI

> Y Combinator-backed (P26), EU-hosted AI sales development platform. Turn a website into an autonomous go-to-market agent that detects buying/social intent, scores prospects against an ideal customer profile, builds warm-lead lists, and runs multichannel (email + LinkedIn) outreach. The Gojiberry AI External API and a hosted MCP server expose contacts, campaigns, lists, lead-source agents, and the unified inbox (Unibox) for programmatic and agent-driven use.

## APIs

- [Gojiberry AI External API (docs)](https://ext.gojiberry.ai/documentation): REST API — contacts, campaigns, lists, agents, unibox, organization, users. Base URL https://ext.gojiberry.ai
- [OpenAPI spec](https://ext.gojiberry.ai/openapi.json): OpenAPI 3.0.0, 28 operations, bearer (JWT) auth, 100 req/min per key.

## MCP

- [Gojiberry MCP server](https://mcp.gojiberry.ai/mcp): Hosted Model Context Protocol server (streamable HTTP, auth required) — run outbound, find/score leads, draft messages, and pull pipeline insights from an AI client like Claude.
- [Connect MCP guide](https://gojiberry.ai/how-to-do-outreach-claude-linkedin-mcp): One-URL setup to connect Claude to Gojiberry.

## Auth

- REST: bearer token — `Authorization: Bearer <API_KEY>`. Create a key at https://app.gojiberry.ai (Settings -> API).
- Org owners can impersonate a member with the `x-impersonate-user-id` header.
- MCP: OAuth 2.1 authorization code + PKCE with dynamic client registration. Scopes `mcp:tools`, `claudeai`.
  - [Protected resource metadata (RFC 9728)](https://mcp.gojiberry.ai/.well-known/oauth-protected-resource)
  - [Authorization server metadata (RFC 8414)](https://mcp.gojiberry.ai/.well-known/oauth-authorization-server)

## Pricing

- PRO — $99/month: 2 AI agents, up to 1,800 prospects contacted/month, unified inbox, lead scoring, email waterfall enrichment, CRM + API + MCP integrations.
- CUSTOM — contact sales, for teams of 5+ and agencies.
- Free trial offered; no published per-call API pricing.

## Events

- Outbound webhooks (configured at https://app.gojiberry.ai/integrations): POST on contact created / contact updated, with an `x-gojiberry-user-id` verification header.
